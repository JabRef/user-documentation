## Multi-paper PDFs

When you import a PDF that contains several papers, such as conference proceedings, JabRef asks whether to create an entry for the whole PDF and one entry per paper, or to import the PDF as one entry. See [Multi-paper PDFs](../multi-paper-pdfs.md).
